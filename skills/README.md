# Project Skills

These repository-local skills encode repeatable Rolecraft workflows for Codex.

## Available Skills

### `$maintain-rolecraft-app`

Use for features, fixes, refactors, schema changes, API changes, UI changes, job source
work, analysis changes, or resume generation changes.

### `$verify-rolecraft-workflows`

Use after implementation, when diagnosing a broken flow, or when confirming that the
local application works from the browser through SQLite and generated files.

### `$resume-updater-agent`

Use to create an evidence-backed JD gap analysis, weighted baseline, and reviewable
resume update strategy before generating a tailored DOCX.

### `$file-reading`, `$docx`, `$pdf-reading`, `$pdf`

Use the local file-processing stack to route, extract, preserve, edit, and review
resume and JD documents without cloud storage or unsupported claim generation.

## Discovery

The skills are stored in the repository so they can be reviewed and versioned with the
application. A Codex environment may need the repository skill path configured or the
skills installed into its normal skill directory before implicit discovery. They can
always be referenced explicitly by path.
