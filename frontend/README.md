# Rolecraft Frontend

Next.js 16 App Router frontend for Rolecraft.

## Commands

```bash
cp .env.example .env.local
npm install
npm run dev
npm run lint
npm run build
```

The API URL is configured with:

```dotenv
NEXT_PUBLIC_API_URL=http://localhost:8000
```

See the repository [README](../README.md), [agent profiles](../agents/README.md), and
[maintenance skill](../skills/maintain-rolecraft-app/SKILL.md) before making substantial
changes.
